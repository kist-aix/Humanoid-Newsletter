# Humanoid Daily — 공개 배포본

「휴머노이드·피지컬 AI 주요동향」의 **공개 지면**이다.
과기정통부 과학기술인공지능혁신과에 평일 아침 보내는 뉴스레터에서
**확인된 결과만** 골라 웹 한 장으로 편 것.

| | |
|---|---|
| 공개 주소 | `https://kist-aix.github.io/Humanoid-Newsletter/` |
| 현재 실린 호 | **2026-09-04** |

## 이 저장소에 있는 것

| 파일 | 무엇 |
|---|---|
| `index.html` | 최신호 한 장. **자립형** — 스타일·스크립트·데이터가 파일 안에 다 들어 있다 |
| `.nojekyll` | GitHub Pages 가 Jekyll 로 처리하지 않게 막는다 |
| `README.md` | 이 문서 |

**외부에서 받아 오는 것이 하나도 없다.** 빌드 도구도, 프레임워크도, CDN 라이브러리도
쓰지 않는다. 그래서 `index.html` 은 내려받아 **더블클릭만 해도 그대로 열린다** —
회선이 끊긴 자리에서도, 파일 하나만 전달받은 사람도 본다.

## 공개면에 무엇을 싣고 무엇을 빼는가

이 지면은 **그대로 전달되는 면**이다. 받는 사람이 배경을 물어볼 곳이 없으므로
확인이 끝나지 않은 것은 올리지 않는다. 아래 넷은 발송본과 내부 화면에는 그대로 있고
**여기에서만 빠진다.**

- **부재 확인 항목** — 「없음·미개설·미발표」. "아직 없다"는 결과가 아니다
- **미확인 수치** — 자체 평가·추정·미제시
- **조건이 밝혀지지 않은 시연** — 자율 여부·시행 횟수·편집 여부 중 하나라도 미확인인 것
- **전망(S4)**

빼는 것이지 지우는 것이 아니다. 「파일럿 종료 후 연장 여부 미발표」 같은 항목은
오히려 내부에서 1순위 재료다.

## 출처 등급

본문의 각 항목에는 근거의 확실성이 붙는다.

| | |
|---|---|
| **S1** | 발표 주체가 낸 원문을 직접 열어 확인 |
| **S2** | 원문에 준하는 1차 자료 |
| **S3** | 보도 등 2차 자료. 원문을 확보하지 못한 경우 |
| **S4** | 전망 — 공개면에는 싣지 않는다 |

단정문은 S1·S2 에서만 쓴다. 시연 영상은 그 자체로 성능 근거가 되지 않는다.

## 갱신하는 법

**이 저장소의 파일을 손으로 고치지 마라.** 원본은 작업 폴더에 있고,
`bundle.py` 가 그날 호를 한 장으로 말아 낸다. 여기 있는 것은 그 산출물의 사본이다.

```bash
python <스킬>/scripts/bundle.py --root <작업폴더>/site \
  --date YYYY-MM-DD -o <작업폴더>/share/web/index.html
```

그 파일을 이 저장소의 `index.html` 로 덮고 밀어 올린다.
`share/HM_YYYYMMDD.txt`(발송 원문) · `share/HM_YYYYMMDD.html`(날짜별 사본) ·
`share/web/index.html`(이 저장소) **셋은 한 세트**이며, 하나만 갱신하면
받는 사람이 보는 것과 우리가 가진 것이 갈라진다.

## Pages 설정

Settings → Pages → Source 를 **Deploy from a branch · `main` · `/ (root)`** 로 둔다.
도메인을 붙이려면 `CNAME` 파일을 루트에 하나 더 만든다.
